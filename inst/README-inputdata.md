
## Input data revisions

The input data revision is the mrmfa version: input data `rev<X.Y.Z>_*_mfa.tgz` is produced by mrmfa X.Y.Z.

To test local or unmerged changes, set a development suffix `cfg$dev` in preprocessing-mfa. The archives are then named `rev<X.Y.Z><dev>_*_mfa.tgz` and do not collide with releases.
